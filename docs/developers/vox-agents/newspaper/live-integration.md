# Newspaper live integration

**Debug → Show newspaper** opens the packaged Steam-Press Broadsheet sample in Civilization V. Follow the [delivery setup](renderer.md#show-an-issue-in-the-game) to test it with the active seat. [Replay](replay.md) issues are available in the browser and CLI output.

[Automatic publication](../../../plans/newspaper/implementation/05-live-integration.md) is planned. The proposal covers checks after completed turns, notifications, and a menu entry for the latest issue.

# Newspaper live integration

**Status: planned.** Every few completed turns, Vox Agents will run the existing editorial check for the human player. It will read MCP's per-game SQLite database through the same dated evidence query as offline replay.

Vox Agents will keep the latest issue in memory for the current game and seat. A notification icon will appear on publication. The icon and the Newspaper entry in the top menu will open the latest issue in the existing reader.

See [Plan 5](../../../plans/newspaper/implementation/05-live-integration.md) for scope and acceptance checks.

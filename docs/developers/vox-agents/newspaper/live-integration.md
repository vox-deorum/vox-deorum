# Newspaper live integration

**Status: Planned.** Live integration will collect evidence for human civilizations, schedule background publication checks, and persist issues and reader state with the game. It will add archive and player controls, coordinate publication with MCP, and keep saved text readable when the service or renderer is unavailable.

The game save is intended to own live publication history and feedback. Offline replay will remain a separate workflow. Scheduling and publication must respect completed-turn boundaries and discard work made stale by loading or switching games.

See [Plan 5: live publication, save persistence, and game reader](../../../plans/newspaper/implementation/05-live-integration.md). Save capacity, collection boundaries, visibility policy, and transport details remain open work in that plan.

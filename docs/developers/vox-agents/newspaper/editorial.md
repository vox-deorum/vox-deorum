# Newspaper editorial decisions

**Status: Planned.** The first editor will use configured triggers, templates, and explicit publication state to choose stories, form series, order pages, and respond to reader feedback without an LLM. A later stage will allow an LLM to propose editorial choices under validated evidence, continuity, and fallback rules.

The renderer consumes completed issues. Editorial logic owns selection and writing decisions, including what continues, merges, fades, or changes prominence.

See [Plan 3: heuristic newspaper and publication state](../../../plans/newspaper/implementation/03-heuristic-editor.md) and [Plan 4: offline reader, LLM editor, and evaluation](../../../plans/newspaper/implementation/04-offline-evaluation.md). Detailed rules remain in those plans.

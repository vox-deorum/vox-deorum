# Newspaper replay and evidence

**Status: Planned.** This stage will build read-only, perspective-specific evidence windows from recorded games. It will preserve cutoff timing, source provenance, subject identity, and visibility limits so later editorial decisions cannot use facts the receiving civilization did not know.

Replay is intended to work offline without a running game, bridge, or live MCP connection. The source recording remains unchanged, and uncertain timelines or incomplete historical data must be reported as limitations.

See [Plan 2: replay and evidence foundation](../../../plans/newspaper/implementation/02-replay.md). This page records scope only; implementation details and verification criteria belong in the plan.

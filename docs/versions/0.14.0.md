## Compatibility

- **Savegame incompatible with v0.13.x and earlier. Start a new game after updating.**
- Games with duplicate civilizations are not currently supported.

## File-Based Agents

- New optional file mode gives agents a workspace where they can look up earlier turn reports, consult game references, run calculations, and keep plans and notes between turns.
- Agents can keep lessons across games through shared notes. Records and notes for the current game rewind when you reload an earlier turn.
- You can download an agent's records and notes from the telemetry dashboard to inspect what it saw and remembered. File mode is off by default.

## Custom Prompts

- Customize agent instructions through editable Markdown files, with shared instructions and overrides for individual civilizations or sessions.

## Strategy and Tactical AI

- Five new tactical flavors let strategic priorities influence battlefield decisions: risk, city capture, attrition, city defense, and holding ground. Improved tactical search, pathfinding, and unit capture.
- New experimental evaluator strategist supports Jev! and chat models, making decisions through structured questions. Requires Flavor mode and manual configuration.
- New strategist turn viewer shows the AI's choices and applied changes, with confidence scores for evaluator decisions.

## Diplomacy and Reports

- Permanent teammates share plans more openly and judge deals by their benefit to the team. Negotiators remember recent proposals and their outcomes to avoid repeating rejected offers.
- Military reports include nuclear weapons and combat support units while respecting visibility. Fixed ideology adoption and Great Person event reporting.

## Reliability and Setup

- Improved prompt caching, long-context handling, and Codex and Claude Code reliability, along with decision pacing and recovery from pauses and reloads.
- Added a DirectX 11 launch setting and a Debug page for viewing and downloading service and game logs.
- Improved installation, updates, and startup checks. Sessions pause if they repeatedly fail to read the game state.

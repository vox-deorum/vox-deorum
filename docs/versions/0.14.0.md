## Compatibility

- **Savegame incompatible with v0.13.6 and earlier.**
- Games with duplicate civilizations are not currently supported.

## File-Based Agents and Custom Prompts

- New optional file access, off by default, lets a civilization's agents browse past turn reports, briefings, and game references, keep plans and notes across turns, and run calculations.
- Records and game notes rewind when you reload an earlier turn. Download them as a zip from the telemetry dashboard or export them from the command line.
- Agent instructions are now plain Markdown prompt files, with custom prompt folders supported per seat or session.

## Strategy and Tactical AI

- Added an experimental evaluator strategist, including Jev! support, that chooses priorities, research, policies, personality, and relationships through structured questions. It requires Flavor mode and manual configuration.
- Added a strategist turn viewer showing proposed changes, confidence, applied actions, and context trimming.
- Added five tactical priorities for risk, city capture, attrition, city defense, and holding ground. The DLL gained tactical search, pathfinding, and capture improvements, including changes backported from Vox Populi 5.4.7.
- Improved event prioritization, decision pacing, model routing, and model caching and context handling, so strategists retain relevant events between decisions and handle large contexts more reliably.

## Diplomacy and Reports

- Improved teammate diplomacy: negotiators now see recent proposal outcomes and avoid repeating rejected offers. Live chats wait for your first message instead of generating an opening greeting.
- Fixed military reports to include nuclear weapons and combat support units while respecting hidden transports. Fixed ideology adoption and Great Person event reporting.

## Reliability and Setup

- Improved pause, reload, and controlled-game handling. Sessions now pause after repeated failures to read the game state.
- Added a Use DX11 game setting that launches the DirectX 11 build by default and falls back automatically on installs without it. Improved startup checks for Vox Populi and localization readiness.
- Improved Codex and Claude Code reliability. Manual updates now install a suitable portable Node.js runtime when needed.
